# Shop User Test

## Goal

Verify the shop browse and purchase flow works end to end for currently authored content.

## Setup

- Open the shop entry point in the hub if available.
- Give the profile enough currency if needed.

## Checklist

- [ ] Confirm the shop opens from the hub.
- [ ] Confirm categories or sections are readable.
- [ ] Select an item and confirm a details surface or equivalent selection state appears.
- [ ] Confirm title, art, description, and price are understandable for the selected item.
- [ ] Buy an item with soft currency and confirm the purchase persists.
- [ ] If premium purchase routing exists, verify the button route is correct without completing a real purchase unless intended.
- [ ] Return to menu and reopen the shop to confirm purchased state is retained.
- [ ] Confirm locked, owned, and purchasable states are visually distinct.

## Expected Result

Browsing and purchasing should feel clear, and item ownership should persist correctly.
