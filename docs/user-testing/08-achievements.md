# Achievements User Test

## Goal

Verify the first achievements shell on the mapped `Achievements` hub destination, including tier visibility, progress evaluation, and persistent claiming.

## Setup

- Open the hub and use the `Achievements` bottom-nav destination.

## Checklist

- [ ] Confirm the achievements surface can be opened from the hub.
- [ ] Confirm the old challenges destination now reads as an achievement-oriented surface rather than a placeholder shell.
- [ ] Confirm at least one achievement shows current progress.
- [ ] Confirm multi-tier progression is understandable.
- [ ] Complete or force progress on one achievement and confirm the progress UI updates.
- [ ] Claim a reward and confirm it cannot be claimed twice.
- [ ] Confirm the claimed reward is reflected in player currency or profile state immediately.
- [ ] Confirm reward values increase appropriately across tiers.
- [ ] Return to the screen and confirm claimed state persists.

## Expected Result

Achievements should create clear long-term goals with persistent, claimable reward states using the existing hub and profile systems.
