This folder contains one manual testing checklist per tracked experience feature.

Use these files when you want to:
- verify a feature in-editor or on device,
- record what passed or failed,
- keep testing focused on player-visible outcomes instead of code structure.

Recommended usage:
1. Open the relevant feature file.
2. Run each checklist item in order.
3. Mark pass/fail and add notes under `Test Notes`.
4. If a feature is not fully playable yet, note the exact blocker instead of skipping silently.
