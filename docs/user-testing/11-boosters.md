# Boosters User Test

## Goal

Verify pre-run boosters can be selected, affect the run, and clear correctly afterward once the feature exists.

## Setup

- Open the pre-run or booster selection flow if available.
- If the feature is not implemented yet, record the blocker.

## Checklist

- [ ] Confirm the booster selection UI can be opened before a run.
- [ ] Confirm boosters are grouped or labeled clearly by effect type.
- [ ] Equip one booster and start a run.
- [ ] Confirm the selected booster produces an obvious effect during the run.
- [ ] End the run and confirm the booster effect does not remain active unexpectedly.
- [ ] Reopen the booster flow and confirm inventory/equipped state is correct.

## Expected Result

Boosters should feel like a clear pre-run choice with visible payoff and clean per-run scoping.
