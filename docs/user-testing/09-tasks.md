# Tasks (Daily / Weekly / Monthly) User Test

## Goal

Verify tasks reset correctly, show progress clearly, and grant rewards through claim actions and milestone tracks.

## Setup

- Open the tasks or progression tasks surface.
- If reset simulation tools exist, have them ready.

## Checklist

- [ ] Confirm daily, weekly, and monthly views can be opened if available.
- [ ] Confirm each task shows progress and reward information.
- [ ] Complete progress on at least one task and confirm the UI updates immediately.
- [ ] Claim a single reward and confirm the reward is granted once.
- [ ] If `Claim All` exists, confirm it grants only eligible rewards.
- [ ] Confirm any milestone or points track updates after claims.
- [ ] Reopen the page and confirm claimed state persists.
- [ ] If time-reset tooling exists, simulate a reset and confirm a fresh task set appears.

## Expected Result

Tasks should feel readable, rewarding, and easy to track at a glance.
