# XP & Levels User Test

## Goal

Verify runs award XP correctly, levels persist, and level-up feedback plus unlock visibility are understandable.

## Setup

- Start from menu with a known profile state.
- Complete one or more runs.

## Checklist

- [ ] Confirm the current level or XP state is visible somewhere in the hub if intended.
- [ ] Finish a run and confirm XP is added to the profile.
- [ ] Confirm XP persists after returning to menu.
- [ ] If leveling up occurs, confirm the new level persists after reopening the game/menu.
- [ ] If a level-up toast appears, confirm it is readable and clears without blocking the hub.
- [ ] Confirm any unlock or level-gated content updates when the required level is reached.
- [ ] Confirm the player can understand why a feature is locked or unlocked.
- [ ] Confirm the top-bar level and XP progress reflect the current profile state after returning to the hub.

## Expected Result

The player should feel steady account progression and understand what leveling is doing for them, including when new hub content becomes available.
