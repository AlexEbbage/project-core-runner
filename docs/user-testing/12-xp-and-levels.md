# XP & Levels User Test

## Goal

Verify runs award XP correctly, levels persist, and any unlock feedback is understandable.

## Setup

- Start from menu with a known profile state.
- Complete one or more runs.

## Checklist

- [ ] Confirm the current level or XP state is visible somewhere in the hub if intended.
- [ ] Finish a run and confirm XP is added to the profile.
- [ ] Confirm XP persists after returning to menu.
- [ ] If leveling up occurs, confirm the new level persists after reopening the game/menu.
- [ ] Confirm any unlock or level-gated content updates when the required level is reached.
- [ ] Confirm the player can understand why a feature is locked or unlocked.

## Expected Result

The player should feel steady account progression and understand what leveling is doing for them.
