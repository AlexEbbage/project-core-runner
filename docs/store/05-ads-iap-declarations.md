# Ads and IAP Declarations

## Ads

Core Racer uses rewarded ads and may use interstitials.

Premium users bypass:

- Continue run ads
- Double run reward ads
- Interstitial ads

Premium users still watch:

- Normal rewarded ads
- Daily reward ad-doubling if enabled
- Mid-run rewarded offers if enabled

## IAP

Primary product:

```txt
premium_user
```

Validate that this exact product id exists in Google Play Console and Unity IAP configuration.
