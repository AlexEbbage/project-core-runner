# Google Play Listing Checklist

## Required listing content

- [ ] App name
- [ ] Short description
- [ ] Long description
- [ ] App icon
- [ ] Feature graphic
- [ ] Phone screenshots
- [ ] Tablet screenshots if supporting tablets
- [ ] Trailer / promo video if available
- [ ] App category
- [ ] Tags
- [ ] Support email
- [ ] Website URL if available
- [ ] Privacy policy URL

## Store declarations

- [ ] Content rating questionnaire
- [ ] Data Safety answers
- [ ] Ads declaration
- [ ] IAP declaration
- [ ] Target audience declaration
- [ ] Families policy decision
- [ ] App access instructions if needed

## Release operations

- [ ] Internal testing track created
- [ ] Closed testing group created if needed
- [ ] Version code incremented
- [ ] Release notes written
- [ ] Staged rollout plan chosen
- [ ] Rollback plan written
