# Content Rating Worksheet

Core Racer expected rating inputs should be reviewed before submission.

Likely answers, subject to final content:

- Violence: fantasy/cartoon obstacle collision only, no gore
- Fear: no horror content unless added later
- Gambling: no real gambling
- User-generated content: no, unless added later
- Online interaction: no, unless backend/social added later
- Purchases: yes, if IAP enabled
- Ads: yes, if ads enabled

Always answer the official questionnaire based on the final shipped build, not the design plan.
