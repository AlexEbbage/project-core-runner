# Accessibility, Haptics and Comfort Checklist

Add UI controls for:

- Screen shake intensity
- Flash intensity
- Motion blur toggle
- Speed lines toggle
- Reduced VFX mode
- High contrast mode
- Colour-blind friendly palette
- Haptics enabled/disabled
- Haptics strength
- Input sensitivity
- Tap zones vs drag controls
- Low-end performance mode

For Core Racer, comfort settings are production-critical because tunnel speed, flashes and screen shake can become uncomfortable quickly.
