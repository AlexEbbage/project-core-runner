# Automated Smoke, Regression and Play Test Plan

## Smoke tests

- Boot services
- Start run
- End run
- Continue run
- Grant rewards
- Save/load profile
- Open shop
- Claim daily reward

## Regression tests

- Premium ad bypass rules
- Rewarded ads still required for normal rewarded placements
- Product catalogue validation
- Daily/weekly/monthly task reset
- Daily login streak logic
- Economy ledger balance consistency
- Clock tamper detection

## Play tests

- Complete tutorial
- Buy first upgrade
- Collect first powerup
- Crash and continue
- Background app mid-run
- Background app after rewarded ad
- Start offline
- Restore premium purchase
- Low-end performance mode
