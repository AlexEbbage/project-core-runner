# Suggested Commands
- Shell is PowerShell on Windows; prefix shell commands with `rtk` per `C:/Users/alexe/.codex/RTK.md`.
- `rtk git status --short` — inspect working tree.
- `rtk rg --files Assets` and `rtk rg <pattern> Assets docs` — fast project discovery.
- Prefer Unity MCP live resources/tools to identify scene state, compile status, console output, screenshots, and Unity tests.
- Use Unity Test Runner/MCP `run_tests` for EditMode or PlayMode; poll the returned job until complete.
